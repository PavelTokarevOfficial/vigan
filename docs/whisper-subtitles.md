# Локальные субтитры

При нажатии «Сделать субтитры и видео» сервер извлекает звук из видео через `ffmpeg` и запускает `whisper.cpp`. Рядом с роликом создаётся один файл `.srt` с репликами и таймкодами. Затем FFmpeg создаёт второй mp4, имя которого начинается с `width-sub-`, и вшивает в него субтитры по центру кадра.

SRT можно открыть на macOS через TextEdit или Quick Look. Новый mp4 проще всего проверить в библиотеке на главной странице: это уже готовое видео с постоянно видимыми субтитрами.

## Модель `models/ggml-tiny.bin`

Это локальная многоязычная модель Whisper Tiny в формате GGML для `whisper.cpp`. Она выбрана для MVP, потому что занимает около 74 МБ и быстро работает на Mac. Точность ниже, чем у `base`, `small` или `medium` — их можно использовать позднее, заменив файл модели и путь `WHISPER_MODEL_PATH` в `server.js`.

Модель применяется для распознавания речи и автоматического определения языка. SRT затем можно передать в FFmpeg для создания отдельного видео со вшитыми субтитрами.
