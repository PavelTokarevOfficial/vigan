# Whisper subtitles

Worker запускает локальный `whisper-cli` с `WHISPER_MODEL_PATH`. Для MVP используется `ggml-tiny.bin`: это самая компактная GGML-модель, поэтому она быстро подходит для коротких Twitch clips и не требует внешнего API. Файл модели не хранится в Git: в Docker он монтируется в `/models`, а путь задаётся в `.env`.

Результат нужен только в SRT (`subtitles/{clipID}/subtitles.srt`). SRT содержит текст и временные интервалы, поэтому FFmpeg может показывать на видео лишь актуальную строку и permanently burn-in её в итоговый MP4. Если качество недостаточно, можно заменить файл модели и `WHISPER_MODEL_PATH` на более крупную совместимую GGML-модель; pipeline и схема БД не меняются.

`WHISPER_MODEL_PATH` обязателен только для worker. API может быть запущен без модели: это позволяет работать со streamer, списком клипов, import и статусами, пока модель ещё скачивается.
