# Скорость обработки

По умолчанию проект использует `-preset ultrafast`, чтобы быстрее обрабатывать видео на ноутбуке. Разрешение, `-crf 20` и качество исходного центрального видео не меняются. При этом итоговый файл может быть больше, чем при более медленном preset.

## Ноутбук

Обычный запуск уже использует быстрый режим:

```bash
npm start
```

## Сервер

На более мощном сервере можно выбрать более эффективное сжатие:

```bash
FFMPEG_PRESET=veryfast npm start
```

Доступные значения соответствуют preset `libx264`, например `ultrafast`, `superfast`, `veryfast`, `faster` и `fast`. Чем медленнее preset, тем дольше обработка, но обычно меньше размер файла при сопоставимом качестве.

## Важно

`ultrafast` не уменьшает разрешение и не отключает размытие фона. Основная нагрузка также приходится на Whisper, масштабирование и blur. Для остановки длительной обработки используйте `Ctrl+C` в терминале.
