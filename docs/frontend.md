# Frontend

Vue 3 + TypeScript + Vite + Pinia + Vue Router + Tailwind. Код размещён в FSD-каталогах: `app`, `pages`, `widgets`, `features`, `entities`, `shared`.

Сейчас реализованы layout, navigation, CRUD Streamers, пакетное добавление Twitch-ников по одному на строку, изменение неотрицательного приоритета числовым полем, поиск Twitch Clips и добавление их в избранное (без автоматического скачивания). Добавление стримеров открывается в модальном окне; логика и UI списка находятся в `features/streamer-manager`, а `StreamersPage` остаётся тонкой route-страницей. Страница `Pipeline` — доска из трёх колонок: «Избранное», «Скаченное» и «Готовые видео». При «В работу» или переносе в третью колонку открывается выбор шаблона; после ответа API карточка немедленно показывает очередь и блокирует повторный запуск. В готовой колонке встроен плеер, ссылки на оригинал и скачивание результата; отдельной страницы видео нет.

В меню шестерёнки есть страницы «Ассеты» и «Шаблоны видео». Ассеты поддерживают S3 upload, preview, create/rename/move/delete folders и rename/move/delete files. Их операции, состояние диалогов и HTTP-вызовы находятся в `features/asset-manager/model/useAssetManager.ts`; UI загрузки, карточек, модалок и workspace с деревом папок — в `features/asset-manager/ui`. `AssetsPage` — тонкая route-страница, которая только подключает `AssetLibraryWorkspace`. Шаблоны имеют список, duplicate/delete и editor: canvas 9:16 на `vue-konva`, упорядоченные слои, drag/resize, hide, duplicate, undo/redo, свойства слоя, dirty indicator и confirmation при уходе. Редактор намеренно даёт приближённый preview — финальным источником истины остаётся FFmpeg worker. FSD используется фактически: editor лежит в `features/template-editor`, DTO-типы — в `entities/{asset,template}`, страницы — в `pages`, общие компоненты/API — в `shared`. Biome форматирует и проверяет frontend: `npm run format`, `npm run lint`; production проверка: `npm run build`.
