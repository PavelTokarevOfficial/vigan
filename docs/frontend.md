# Frontend

Vue 3 + TypeScript + Vite + Pinia + Vue Router + Tailwind. Код размещён в FSD-каталогах: `app`, `pages`, `widgets`, `features`, `entities`, `shared`.

Сейчас реализованы layout, navigation, CRUD Streamers, пакетное добавление Twitch-ников по одному на строку, поиск Twitch Clips и добавление их в избранное (без автоматического скачивания). Страница `Pipeline` — доска из трёх колонок: «Избранное», «Скаченное» и «Готовые видео». Кнопки дублируют действия drag-and-drop: перенос избранного в «Скаченное» создаёт download job, перенос скаченного в «Готовые видео» создаёт process job. Process job немедленно отображается как «В очереди на обработку» и повторный запуск недоступен до завершения или ошибки. В готовой колонке встроен плеер, ссылки на оригинал и скачивание результата; отдельной страницы видео нет. Header использует локально добавленный `shadcn-vue` Dropdown Menu: основная навигация находится рядом с логотипом, сервисные ссылки — в меню по Lucide-шестерёнке. Компоненты shadcn-vue лежат в `shared/ui/shadcn`, а их helper — в `shared/lib`, чтобы сохранить FSD. FSD используется фактически: `widgets/AppHeader`, `features/clip-import/ClipImportButton`, DTO-типы в `entities`, а общие `AppButton`, `EmptyState`, `ErrorState` и HTTP helper — в `shared`. Biome форматирует и проверяет frontend: `npm run format`, `npm run lint`; его встроенный experimental HTML mode обрабатывает Vue SFC template, отдельный Vue plugin не нужен. Production проверка: `npm run build`.
