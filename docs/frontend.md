# Frontend

Vue 3 + TypeScript + Vite + Pinia + Vue Router + Tailwind. Код размещён в FSD-каталогах: `app`, `pages`, `widgets`, `features`, `entities`, `shared`.

Сейчас реализованы layout, navigation, CRUD Streamers, поиск Twitch Clips и добавление их в избранное (без автоматического скачивания). Страница `Pipeline` — доска из трёх колонок: «Избранное», «Скаченное» и «Готовые видео». Кнопки дублируют действия drag-and-drop: перенос избранного в «Скаченное» создаёт download job, перенос скаченного в «Готовые видео» создаёт process job. В готовой колонке встроен плеер, ссылки на оригинал и скачивание результата; отдельной страницы видео нет. FSD используется фактически: `widgets/AppHeader`, `features/clip-import/ClipImportButton`, DTO-типы в `entities`, а общие `AppButton`, `EmptyState`, `ErrorState` и HTTP helper — в `shared`. UI libraries не используются. Biome форматирует и проверяет frontend: `npm run format`, `npm run lint`; его встроенный experimental HTML mode обрабатывает Vue SFC template, отдельный Vue plugin не нужен. Production проверка: `npm run build`.
