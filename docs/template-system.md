# Шаблоны и ассеты

Шаблон — это версия JSON-конфигурации композиции, а не строка FFmpeg из браузера. В ней заданы canvas и упорядоченные слои: исходный Twitch-клип, ассет, субтитры, текст или фон. Координаты хранятся в реальных пикселях canvas 1080×1920; редактор показывает уменьшенную копию.

Файлы ассетов находятся в object storage по неизменяемому ключу `assets/{assetID}/original`. Переименование и перемещение меняют только метаданные PostgreSQL. Браузер получает короткую presigned-ссылку, но не получает S3-ключи и учётные данные.

При отправке клипа в обработку backend валидирует конфигурацию шаблона и сохраняет в `processing_jobs.template_snapshot` неизменяемый JSON со ссылками на ассеты. Поэтому изменение шаблона после постановки задачи не меняет уже ожидающий или выполняемый рендер.

`Классический vertical` создаётся миграцией как первый шаблон и повторяет текущий результат: размытый фон, видео по центру и burned-in SRT. Старые задачи без снимка продолжают использовать совместимый fallback, пока не будут завершены или удалены.
